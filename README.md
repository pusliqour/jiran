# Jiran team demo

Connected frontend for the Jiran inventory and stock-exchange project.

The application connects over HTTPS to an authenticated Python gateway running on the project owner's Mac. The gateway keeps Supabase development tokens and administrative endpoints private. Team members sign in with demo credentials provided separately by the project owner.

This is a temporary team demonstration. The Mac, Python gateway, database and HTTPS tunnel must remain running. The tunnel URL changes if it is recreated.

The imported dataset's original provenance is awaiting owner confirmation. It is historical demonstration data, not a live POS feed. Raw store files, passwords, service-role keys and trained model artifacts are not included in this repository.

Stock labels follow an explicit inventory policy. The learned model remains experimental; displayed model support is not a guarantee of business outcomes.
